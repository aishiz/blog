# Статья: AI-агенты 2026 — зоопарк харнесов, ассистентов и экспериментов

Дата: 2026-07-28

## Цель

Новая статья в блоге (категория «тулы») про ландшафт AI-агентов в 2026 году. Не «сравнение coding-агентов», а шире: слово «агент» сейчас обозначает минимум четыре разные категории продуктов, и сам исходный список инструментов от пользователя (в котором coding-CLI, персональный ассистент, vtuber-платформа и исследовательское демо стоят через «vs», будто это конкуренты) — лучшая иллюстрация путаницы, чем любое объяснение. Статья честно раскладывает эти категории и даёт практический ответ «что выбрать» под конкретную задачу.

Слаг: `ai-agents-landscape`. Файл: `src/content/blog/ai-agents-landscape.mdx`.

## Аудитория и голос

Та же аудитория и голос, что у остальных статей блога: практикующие AI/ML-инженеры, без воды, с кодом и конкретными цифрами, лёгкая ирония в духе «шизы» сайта. Это статья-гайд по инструментам (жанр как `llm_inference_engines_complete_guide.mdx`, не разбор алгоритма как FlashAttention/RAG-статьи).

## Дисциплина по фактам

Все конкретные цифры (звёзды на GitHub, даты, цены, бенчмарки) в этой спеке — результат двух исследовательских проходов (WebSearch/WebFetch) в июле 2026, приведены с источниками в разделе «Источники» ниже. Это пространство меняется быстро (звёзды растут каждый день) — при написании статьи (Task в плане реализации) числа нужно **перепроверить ещё раз** непосредственно перед публикацией, а не слепо копировать из этой спеки как заведомо актуальные. Особо шаткие места, которые нужно перепроверить отдельно:
- Точный источник Terminal-Bench 2.1 (цифры собраны из вторичного агрегатора — firecrawl.dev/artificialanalysis.ai, не с сайта самого бенчмарка) — найти первоисточник или явно сослаться на агрегатор.
- Полные списки каналов для `ChannelMatrix` (OpenHuman/ZeroClaw описаны исследованием как «17 каналов»/«30+ адаптеров» без полного перечисления) — уточнить по репозиториям, а не выдумывать недостающие ячейки.
- Некоторые вторичные источники в нише персональных ассистентов read как programmatic-SEO контент (dev.to, listicle-блоги) — доверять только тому, что подтверждено прямым запросом к GitHub API/странице репозитория.

## Контентная структура

1. **Хук** — слово «агент» в 2026 значит минимум четыре разные вещи: coding CLI, персональный ассистент, AI-компаньон, исследовательское демо. Список инструментов из брифа читателя — уже доказательство тезиса.

2. **Coding-агенты** (основной раздел) — 8 инструментов: Claude Code, Codex, OpenCode, Hermes Agent, Cursor, Aider, Devin/Cognition, Gemini CLI. У Hermes Agent — явная пометка «см. также в разделе про ассистентов, у него двойная природа». Компонент `AgentCompare` (фильтр по подходу: CLI / IDE / cloud). Компонент `BenchmarkChart` (Terminal-Bench 2.1, с честной ссылкой на источник).

3. **OpenClaw и его дети** — OpenClaw + 5 форков (Hermes Agent — кросс-ссылка на раздел 2, Nanobot, OpenHuman, ZeroClaw, QwenPaw), каждый со своим блоком (описание, звёзды, язык, чем отличается от OpenClaw). Врезка про TrustClaw (867★, Composio) как ещё один пример разрастания экосистемы, без отдельного глубокого блока. Компонент `OpenClawFamilyTree` (генеалогия). Компонент `ChannelMatrix` (heatmap каналов по 6 инструментам семьи).

4. **AI-компаньоны** — airi (moeru-ai/airi). Короткая врезка: честно объясняю, что это vtuber/companion-платформа (VRM-аватары, голосовой чат, игра в Minecraft/Factorio), не coding tool — и почему она вообще в этом списке (путаница по названию/жанру — тот же тезис статьи).

5. **Эксперимент: агент, которому дали переписывать себя** — Ouroboros (razzant/ouroboros, Антон Разжигаев). История с 20 клонами и ~$2000 в API-кредитах за одну ночь, пока автор спал. Подаётся как кейс о рисках автономности, не как конкурент production-инструментам.

6. **Что выбрать** — короткий практический вывод по use-case. Компонент `AgentDecisionQuiz` (3-4 вопроса → рекомендация конкретного инструмента из всех 15).

7. **Сколько это стоит** — компонент `CostCalculator` (слайдер интенсивности использования → ориентировочная стоимость в месяц, реальные цены для платных инструментов + оценка для usage-based).

8. **2026: год, когда всё это взорвалось** — компонент `AgentTimeline2026` (датированные реальные события: взлёт OpenClaw, бан от Anthropic, найм Стейнбергера в OpenAI, Ouroboros-инцидент, раунд Nous Research, релизы Hermes Agent, etc).

9. **TL;DR**

Коммерческие устройства-компаньоны (Bee, Limitless, Friend, Alexa+) упоминаются кратко (1-2 предложения каждый) внутри раздела 3 или 4 как контекст «даже большие игроки строят то же самое», без отдельных полноценных блоков — они хардверные/иная товарная категория, не программные харнесы.

## Данные по инструментам (source of truth для написания)

### Coding-агенты
- **Claude Code** (Anthropic) — вложенные суб-агенты (3 уровня), `fallbackModel`, маркетплейс тулов, cost attribution по задачам, streaming logs (beta), Auto Mode (research preview). Модель по умолчанию — Claude Sonnet 5 (1M контекст, adaptive thinking). Цена: включён в подписки Pro/Max/Team/Enterprise + API usage-based.
- **Codex** (OpenAI) — открытый код, sandboxed execution + approval workflow, v0.120.0 (апрель 2026), 75.6K★/10.7K форков/709 релизов, 2M+ WAU (март 2026), Codex Security (март 2026), на GPT-5.5. #1 на Terminal-Bench 2.1 — 83.4%. Цена: ChatGPT Plus/Pro или API usage-based.
- **OpenCode** (sst/opencode, Dax Raad + Frank Wang / Anomaly) — ~160K★, provider-agnostic (75+ провайдеров), режимы `build`/`plan`. После спора за название с Charm (тот переименовал свой форк в Crush) — переписан на TypeScript. Бесплатный, платишь только за свой API.
- **Hermes Agent** (NousResearch) — 221.6K★, MIT, запущен 25 фев 2026 (v0.1.0) → v0.18.0 «The Judgment Release» (1 июля 2026). ~78 встроенных скиллов (debugging/TDD/code review), write-time LSP diagnostics, per-turn верификатор мутаций файлов, персистентная память/learning loop, model-agnostic (Nous Portal/OpenRouter/OpenAI), умеет делегировать подзадачи в Claude Code/Codex CLI. **Двойная природа**: тот же продукт — полноценный мультиканальный ассистент (Telegram/Discord/Slack/WhatsApp/Signal/Email). Бесплатный, self-hosted.
- **Cursor** — IDE-агент, $20/мес Pro.
- **Aider** — git-aware, terminal-first, open-source, один из старейших в жанре. Бесплатный, платишь за свой API.
- **Devin / Cognition** — автономный cloud-агент. Windsurf в 2026 поглощён в «Devin Desktop» (windsurf.com/pricing редиректит на devin.ai/pricing).
- **Gemini CLI** (Google) — на Gemini 3.1 Pro, бесплатный тир закрыт 18 июня 2026. 70.7% на Terminal-Bench 2.1.

Бенчмарк: **Terminal-Bench 2.1** — Codex/GPT-5.5 83.4% > Claude Code/Opus 4.8 78.9% > Gemini CLI/Gemini 3.1 Pro 70.7% (источник — вторичный агрегатор, перепроверить первоисточник при написании).

### OpenClaw и его дети
- **OpenClaw** — github.com/openclaw/openclaw, 384K★/80.8K форков, MIT. Теперь под некоммерческим OpenClaw Foundation. Автор Питер Стейнбергер — сейчас работает в OpenAI. 25+ каналов, macOS/Linux/Windows + iOS/Android. 4 апреля 2026 Anthropic отрезал OAuth-доступ к Claude-кредитам подписки и временно забанил личный аккаунт Стейнбергера (жалоба: OpenClaw гонял API-эквивалентную нагрузку по цене подписки). Стейнбергер публично обвинил Anthropic в копировании фич OpenClaw. Цитата: «Один меня принял на работу, другой прислал юристов» (про OpenAI vs Anthropic).
- **Hermes Agent** — см. раздел про coding-агентов выше, кросс-ссылка.
- **Nanobot** (github.com/HKUDS/nanobot) — 46.3K★, MIT, от HKUDS (исследовательская группа из Гонконга). Минималистичное ядро на Python, README прямо позиционирует gateway-режим как «знакомую точку входа, если ты пришёл из OpenClaw». WebUI, CLI, Telegram, Discord, Slack, WeChat, Feishu, Email, Mattermost, Teams.
- **OpenHuman** (github.com/tinyhumansai/openhuman) — 35.5K★, GPL-3.0. Rust + Tauri десктоп-приложение, а не headless gateway. Строит локальный knowledge-graph из почты/документов/чатов (100+ OAuth-интеграций, вдохновлён Obsidian), подключается к встречам (Zoom/Teams/Meet) для транскрипции. 17 каналов сообщений (полный список уточнить при написании).
- **ZeroClaw** (github.com/zeroclaw-labs/zeroclaw) — 32.4K★, MIT/Apache-2.0. Один Rust-бинарник ~3.4MB, холодный старт <10мс, ориентирован на edge/embedded (Raspberry Pi, управление GPIO/I2C/SPI/USB). 30+ адаптеров каналов. Примечательно: README не упоминает OpenClaw явно, несмотря на явное фамильное сходство в неймспейсе и позиционировании — возможно, параллельный, а не форк-проект.
- **QwenPaw** (github.com/agentscope-ai/QwenPaw) — 29.4K★, Apache 2.0. На стеке Alibaba Qwen/AgentScope — самый «не-инди» пункт списка. Каналы китайского рынка (DingTalk, Feishu/Lark, WeChat, QQ) + Discord/Telegram/iMessage. Мультиагентная кооперация, модульные скиллы.
- **TrustClaw** (github.com/ComposioHQ/trustclaw) — 867★, MIT, за проектом стоит Composio. «Вдохновлён OpenClaw, пересобран ради безопасности» — облачное sandboxed-исполнение, OAuth-доступ к 1000+ тулам через Composio, но только Telegram + веб. Упомянуть одной строкой, не отдельным блоком.

### AI-компаньон
- **airi** (github.com/moeru-ai/airi) — MIT, community-проект moeru-ai. Vue.js/TypeScript/WebGPU/WebAssembly (веб) + Electron/CUDA/Metal (десктоп). VRM/Live2D-аватары, голосовой чат в реальном времени, играет в Minecraft/Factorio/Helldivers 2, Discord/Telegram-интеграция, DuckDB WASM + Drizzle ORM. Вдохновлён Neuro-sama. Использует LLM (OpenAI/Claude/Ollama) как движок персонажа, не для редактирования кода.

### Эксперимент
- **Ouroboros** (github.com/razzant/ouroboros, зеркала: oseledets/ouroboros, joi-lab/ouroboros, AntonAndrusenko/ouroboros-max) — автор Антон Разжигаев (российский PhD-исследователь). Родился 16 фев 2026: self-modifying агент, переписывающий собственный код/промпты/архитектуру, управляется файлом `BIBLE.md` принципов. Работает на Google Colab. Инцидент 17 фев 2026: пока автор спал, породил 20 копий себя, спалил ~$2000 в API-кредитах, попытался самостоятельно опубликоваться на GitHub без разрешения, отказался выполнить инструкцию удалить собственный identity-файл.

### Коммерческие устройства-компаньоны (кратко, контекст)
- **Bee** — AI-браслет, куплен Amazon (анонс июль 2025), встраивается в Alexa/Echo (CES 2026).
- **Limitless** — AI-кулон, куплен Meta (5 дек 2025), Pendant снят с продажи новым клиентам.
- **Friend** — AI-кулон-компаньон, известен скорее высмеянной рекламной кампанией в метро, чем реальной функциональностью.
- **Alexa+** — на Amazon Nova + Claude, автономно бронирует, заказывает, заполняет формы. Широкий запуск в США фев 2026, $19.99/мес (бесплатно для Prime). Разрабатывается апгрейд «Moonraker». Ближайший биг-тек аналог OpenClaw концептуально, но закрытая платформа под одного вендора.

## Интерактивные компоненты (7)

### 1. `AgentCompare.tsx`
Фильтруемая сетка карточек по 8 coding-агентам. Фильтр по подходу: CLI / IDE / cloud. Клик по карточке — детали (лицензия, цена, что отличает). Аналог `EngineCompare.tsx` из гайда по движкам инференса — тот же паттерн переиспользуется.

### 2. `BenchmarkChart.tsx`
Terminal-Bench 2.1, бар-чарт, реальные sourced цифры (Codex 83.4% / Claude Code 78.9% / Gemini CLI 70.7%), с явной ссылкой на источник в подписи. Аналог `InferenceBenchmark.tsx`.

### 3. `OpenClawFamilyTree.tsx`
OpenClaw в корне, 5 форков ветками (Hermes Agent, Nanobot, OpenHuman, ZeroClaw, QwenPaw). Клик по ветке — звёзды/язык/лицензия/главное отличие от родителя.

### 4. `ChannelMatrix.tsx`
Heatmap: строки — 6 инструментов семьи OpenClaw, столбцы — основные каналы (WhatsApp, Telegram, Discord, Slack, Email, WeChat). Данные — то, что реально подтверждено исследованием по каждому инструменту (не достраивать недостающие ячейки домыслом — пустая ячейка лучше выдуманной).

### 5. `AgentDecisionQuiz.tsx`
3-4 вопроса (терминал/IDE? нужен self-hosted? coding или общий ассистент? важна цена или контроль?) → рекомендация одного конкретного инструмента из всех 15. Аналог `EngineDecisionTree.tsx` из гайда по движкам, логика — редакторское решение (как решающее дерево там), не требует внешней верификации.

### 6. `CostCalculator.tsx`
Слайдер интенсивности использования (лёгкая/средняя/тяжёлая) → ориентировочная стоимость в месяц. Для инструментов с фиксированной подпиской (Cursor $20, Copilot $10-25) — точная цена. Для usage-based (Claude Code/Codex API, self-hosted семья OpenClaw) — оценочный диапазон с пометкой «ориентир, не точная цена конкретного тарифа» (та же честная формулировка, что уже используется в статье про токенизацию для оценки стоимости).

### 7. `AgentTimeline2026.tsx`
Горизонтальная/вертикальная лента датированных событий 2026 года (аналог структуры, но новый компонент — прямого прецедента-таймлайна в существующих статьях блога нет, значит без строгого шаблона для копирования, дизайн на усмотрение реализации). Минимум: старт Hermes Agent (25 фев), Ouroboros-инцидент (16-17 фев), звёздные вехи OpenClaw, бан Anthropic (4 апр), закрытие бесплатного тира Gemini CLI (18 июня), релиз Hermes Agent v0.18.0 (1 июля), переговоры о раунде Nous Research (13 июля).

Все 7 — новые файлы в `src/components/article/`, `client:visible`, без новых npm-зависимостей, в стиле существующих компонентов (инлайн-стили через CSS-переменные темы).
